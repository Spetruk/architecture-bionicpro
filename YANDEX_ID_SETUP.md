# 🎯 Настройка Яндекс ID для BionicPRO

## 📋 Пошаговая инструкция

### 1. Создание приложения в Яндекс OAuth

1. Перейдите на https://oauth.yandex.ru/
2. Войдите в свой аккаунт Яндекса
3. Нажмите **"Создать приложение"**
4. Заполните форму:
   - **Название**: BionicPRO
   - **Описание**: Система управления бионическими протезами
   - **Иконка**: Загрузите логотип (опционально)
   - **Сайт**: http://localhost:3000
   - **Callback URL**: `http://localhost:8080/realms/bionicpro/broker/yandex/endpoint`

5. Выберите **разрешения**:
   - ✅ `login:info` - Доступ к логину, имени, фамилии и полу
   - ✅ `login:email` - Доступ к адресу электронной почты
   - ✅ `login:avatar` - Доступ к аватару (опционально)

6. Нажмите **"Создать приложение"**

### 2. Получение учетных данных

После создания приложения вы получите:
- **Client ID** (ID приложения)
- **Client Secret** (Пароль приложения)

**⚠️ Сохраните эти данные - они понадобятся для настройки Keycloak!**

### 3. Обновление конфигурации Keycloak

Откройте файл `keycloak/realm-export-auto.json` и найдите секцию с Яндекс ID:

```json
{
  "alias": "yandex",
  "displayName": "Яндекс ID",
  "config": {
    "clientId": "your-yandex-client-id",      // ← Замените на ваш Client ID
    "clientSecret": "your-yandex-client-secret" // ← Замените на ваш Client Secret
  }
}
```

**Замените:**
- `your-yandex-client-id` на ваш **Client ID**
- `your-yandex-client-secret` на ваш **Client Secret**

### 4. Перезапуск системы

```bash
docker-compose down -v
docker-compose up -d
```

## 🧪 Тестирование

### 1. Базовый flow аутентификации

1. Откройте http://localhost:3000
2. Нажмите **"Войти"**
3. На странице Keycloak выберите **"Яндекс ID"**
4. Войдите в свой аккаунт Яндекса
5. Разрешите доступ к данным
6. Система перенаправит на экран согласия: http://localhost:3000/consent
7. Выберите **"Разрешить использование данных"** или **"Отклонить"**
8. Попадете в дашборд с информацией о пользователе

### 2. Проверка сохранения данных

Проверьте, что данные пользователя сохранились в БД:

```bash
# Подключитесь к PostgreSQL
docker exec -it bionicpro-postgres psql -U postgres -d bionicpro

# Проверьте таблицу пользователей
SELECT * FROM user_profiles;
```

### 3. API эндпоинты

Проверьте работу User Profile Service:

```bash
# Health check
curl http://localhost:8002/health

# Получить профиль пользователя (замените KEYCLOAK_ID)
curl http://localhost:8002/users/{KEYCLOAK_ID}

# Обновить согласие
curl -X POST http://localhost:8002/users/consent \
  -H "Content-Type: application/json" \
  -d '{"keycloak_id": "KEYCLOAK_ID", "consent_given": true}'
```

## 🎯 Особенности реализации

### Identity Brokering
- Keycloak выступает как посредник между приложением и Яндекс ID
- Пользователи аутентифицируются через Яндекс, но управляются в Keycloak
- Автоматическое создание локальных пользователей при первом входе

### Согласие на данные
- После первого входа через Яндекс система показывает экран согласия
- Пользователь может разрешить или запретить использование данных
- Решение сохраняется в БД и влияет на доступные функции

### Синхронизация профиля
- Данные из Яндекса автоматически синхронизируются с локальной БД
- Сохраняются: имя, фамилия, email, Яндекс ID
- Возможность расширения для дополнительных атрибутов

### MFA Integration
- Даже пользователи Яндекс ID должны настроить MFA (TOTP)
- Это обеспечивает единый уровень безопасности для всех пользователей

## 🚨 Безопасность

### Рекомендации для продакшена:

1. **HTTPS обязателен** для всех callback URL
2. **Храните Client Secret в переменных окружения**, не в коде
3. **Настройте CORS** правильно для production доменов
4. **Логируйте все операции** с пользовательскими данными
5. **Регулярно обновляйте** токены и ротируйте секреты

### Пример для продакшена:

```bash
# Переменные окружения
export YANDEX_CLIENT_ID="your-production-client-id"
export YANDEX_CLIENT_SECRET="your-production-client-secret"
export YANDEX_CALLBACK_URL="https://your-domain.com/realms/bionicpro/broker/yandex/endpoint"
```

## 🆘 Troubleshooting

### Проблема: "Invalid client_id"
- Проверьте, что Client ID правильно скопирован из Яндекс OAuth
- Убедитесь, что нет лишних пробелов

### Проблема: "Invalid redirect_uri"
- Callback URL должен точно совпадать с настройкой в Яндекс OAuth
- Формат: `http://localhost:8080/realms/bionicpro/broker/yandex/endpoint`

### Проблема: Экран согласия не появляется
- Проверьте, что User Profile Service запущен на порту 8002
- Убедитесь, что PostgreSQL содержит таблицу user_profiles

### Проблема: Данные не сохраняются в БД
- Проверьте логи User Profile Service: `docker-compose logs user-profile-service`
- Убедитесь в корректности подключения к PostgreSQL
